# Kerenga Cargo Couriers — Fresh Rebuild

This directory is a clean second-generation application built from the useful capabilities of the original Kerenga Cargo Carriers project.

## Architecture
- Frontend: React + TypeScript + Vite
- Backend: Node.js + Express API
- Database: Firebase Firestore
- Authentication: Firebase Authentication
- Deployment target: Vercel (frontend/API) or equivalent Node hosting

## Core modules
- Public homepage
- Cargo booking
- Quote requests
- Public shipment tracking
- Customer portal
- Driver workplace
- Staff/operations workplace
- Admin command center
- Fleet and vehicle management
- Shipment/trip management
- Documents
- Finance
- Notifications
- Audit logs
- Company branding/settings

The old application remains untouched on `main`. This rebuild is on branch `fresh-rebuild-2026`.
